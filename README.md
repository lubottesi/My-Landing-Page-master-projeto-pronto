# My Landing Page (projeto pronto)

A copy of [My-Landing-Page-master](https://github.com/lubottesi/My-Landing-Page-master) - same code, deployed separately. It's a minimal personal landing page in React, built on top of [My-Landing-Page](https://github.com/singhkshitij/My-Landing-Page) by Kshitij Singh (MIT) while practicing React.

**Live:** https://my-landing-page-master-projeto-pronto.vercel.app

## Running locally

```bash
npm install
npm start
```
